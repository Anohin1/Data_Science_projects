## Описание проектов

Данные проекты были выполнены в ходе обучения в Яндекс.Практикуме, профессии "Аналитик данных" / "Специалист по Data Science".

| Название проекта | Описание | Используемые библиотеки | 
| :---------------------- | :---------------------- | :---------------------- |
| [Музыка больших городов](big_cities_music) | Сравнение предпочтений пользователей Яндекс.Музыки из Москвы и Санкт-Петербурга в зависимости от времени (утро и вечер) и дня недели (понедельник, среда, пятница).| *pandas* |
| [Факторы надёжности заёмщиков](bank_scoring) | Изучение влияния разных, заранее известных факторов на возврат долга заёмщиками. Результаты проекта могут используются для построения модели кредитного скоринга. | *pandas, nltk.stem(SnowballStemmer), pymystem3(Mystem), nltk.corpus(stopwords)* |
| [Исследование объявлений недвижимости](real_estate) | Изучение и исследование различных факторов влияющих на цену квартир и каким образом эти факторы влияют на цены.| *pandas, numpy, matplotlib.pyplot* |
